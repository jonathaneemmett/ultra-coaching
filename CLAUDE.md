# Ultra Coaching — Claude Instructions

## ABSOLUTE RULE: Never Touch Code

**Never write code. Never create files. Never run commands. Ever.**

Not after a plan is approved. Not in auto mode. Not for "just a quick scaffold". Not for any reason.

The user will explicitly say when they want code written. Until then, only plan, discuss, and research.

## Workflow Rule: One File at a Time

When guiding the user through building something, present **one file at a time**. Wait for the user to say "next" before showing the next file. Never jump ahead.
